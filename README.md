
# AI-Powered Sales Forecasting and Inventory Optimization

## Project Overview

This project predicts future product demand using Machine Learning
and recommends inventory replenishment actions based on forecasts,
current stock, supplier lead times, and inventory constraints.

## Main Features

- Sales demand forecasting
- Inventory optimization and reorder recommendations
- Stockout risk monitoring
- Interactive business dashboard
- Database-backed sales and stock transactions
- LLM-powered explanations and recommendations

## Technology Stack

- Python
- Pandas and NumPy
- Scikit-learn and gradient-boosting models
- FastAPI
- SQLite and SQLAlchemy
- Streamlit and Plotly
- Ollama or a hosted LLM API
